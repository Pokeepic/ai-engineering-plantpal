# Data handling

The initial corpus is defined in [the project scope](../docs/week1_project_scope.md#data-sources).

This folder currently contains documentation only. Store permitted local downloads in `data/raw/` and extracted content in `data/processed/`; both are ignored by Git. Record source URL, publisher, title, retrieval date, version, checksum, and usage terms when ingestion begins. Preserve document/page identifiers for citations. Do not assume that a public URL grants redistribution rights.
